# Sugar Lab

Одностраничный сайт студии электроэпиляции Sugar Lab (Екатеринбург, ул. Луначарского, 133).

- `index.html` — главная страница
- `privacy.html`, `consent.html`, `cookies.html`, `terms.html` — правовые документы
- `img/` — фотографии и фигура для карты зон
- `fonts/` — шрифты Forum и Golos Text (локально, без Google Fonts)

Яндекс Метрика подключается после согласия посетителя: укажите номер счётчика в `METRIKA_ID` в `index.html`.
Перед публикацией заполните реквизиты, отмеченные `[...]`, в футере и правовых документах.
